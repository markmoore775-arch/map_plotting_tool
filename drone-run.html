Drone Run

Top-down arcade run: your craft uses the AirPlot logo. Dodge Airspace-style plane silhouettes (blue / teal / green / amber / purple; obstacles are never red). Destroy the red emblem targets. For fun only, not flight training.

  • Move: WASD or arrow keys; drag on touch.
  • Shoot: Space (desktop); on phones, auto-fire plus the Fire button.
  • Lives: Three hits; score from distance and destroyed targets.
  • Performance: Turn on if the game stutters (lower resolution, no map tiles, simpler effects).
