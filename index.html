Mapping, weather, flight documentation, and checklists in one place.

AirPlot combines an interactive map for areas and points, location-based weather with METAR/TAF, live airspace traffic with hazard-themed red tracks (optional glider-class OGN overlay), always-on altitude labels, and session trails, structured flight reports you can share or export, and checklists with progress and exports. Choose a tool below to get started.

      Save files, full tool summaries

      Planning: Draw and edit on an interactive map: points (types, colours, icons, per-point notes), shapes (circle, rectangle, polygon, line, arrow, flight path, text, grid overlay), UK airspace (prohibited, restricted, danger, FRZ, NOTAM, RA(T)), layer switcher (e.g. OSM, topo, satellite, optional Mapbox or Ordnance Survey), geolocation, search, bulk import (CSV / paste), export (CSV, KML, map screenshot, branded PowerPoint and PDF), save/load project (JSON), undo and redo, Flight Overview and distance on flight paths, and optional elevation (Mapbox token).

      Weather: Tap the map to select a location, pick a forecast model (for example ECMWF IFS, GFS, UK Met Office, GEM Canada), and fetch for “now” or a chosen time. Reports include summary, 12-hour forecast, wind at 10 m and 120 m AGL, METAR/TAF (decoded or raw), an Airspace tab (NOTAMs and UK zones for a search radius you set, with small maps per item), and export to PowerPoint or PDF with a Dark or Light export theme (default Light). Exports use that radius for NOTAM and airspace content; PowerPoint includes a small map per NOTAM and per zone plus an overview; PDF adds the same per-item maps in a map-and-details table plus an overview map.

      Airspace: From the welcome screen, Airspace can open a chooser: AirPlot Airspace (full-screen map, ADSB.lol live JSON; red aircraft icons by altitude band; altitude (ft) beside tracks; optional OGN (FLARM-class) traffic in cyan from the Open Glider Network; optional approx. AGL with a Mapbox token in js/config.js; session trails; tap for detail; auto-refresh pauses while details are open) or ADS-B Exchange (embedded third-party globe for testing). Not for separation or compliance: situational awareness only.

      Flight Report: Capture when and where (address or coordinates, Use current GPS on HTTPS with optional mini-map and postcode), mission details (reference, deconflictions, remote pilots, UAS), up to four battery entries, optional Fetch weather report into the form (Open-Meteo), an Airspace section (NOTAMs and UK zones near your coordinates with small maps), free-text notes, Theme (Dark / Light) for the page, PDF theme (Dark / Light, default Light) for exported PDFs, Export PDF, and Send by email. Your draft is saved in this browser until you use Clear report (top), Clear form (bottom, both with confirmation), or clear site data. Use the Checklist link in the header to open the M4T / TD checklist without returning to the welcome screen.

      Checklist: The M4T / TD page runs a multi-section checklist (pre-flight, take-off, landing, post-flight) with checkboxes, per-section progress, optional note fields for key settings, Reset All (with confirmation), Send by email, Export to PDF (print), and an exported timestamp. State is stored locally in your browser so you can switch to Flight Report or other tools and come back. Use Flight Report in the header to open it without going home.

      Save files: Planning Save Project / Load Project JSON uses the same format as v2; older project files still load.

      Adding Points

      Add points via the sidebar form, or use the pin (Drop Point) control on the map toolbar: open it, pick a point type from the icon strip, then click the map once to place. Optional Notes are stored with each point and appear when you edit the point.

      Location formats supported: UK postcode, decimal lat/lng, Ordnance Survey grid reference, degrees/minutes/seconds (DMS), and What3Words (requires API key in Settings).

      Point Types & Icons

      Address/Reference, Primary TOLA, Secondary TOLA, Custom TOLA, Emergency Landing Zone, No-Fly Marker, Hazard, Waypoint, Custom Point, House, and TOLA. Custom Point can use a 1–2 character symbol. Many types support icon colour (colour picker or palette) so you can distinguish markers on the map.

      Managing Points

      Use the search box to filter points. Click a point in the list to pan to it and highlight it. Use the edit and delete buttons, or right-click a marker on the map. Drag markers to move them. Click a marker to see a quick-edit popup with label, elevation, and links to View Details or Edit. Double-click a marker or use “View Details” for coordinates in multiple formats (Decimal, DMS, OS Grid Ref, What3Words, Elevation) with copy-to-clipboard. Use Copy All in the Point Details modal to copy all coordinate formats at once.

      Elevation

      Points can display elevation (metres AMSL) when a Mapbox token is configured. Use the Always display elevation on map checkbox when adding or editing a point to show elevation in the quick-edit popup and point list.

      Drawing shapes & text

      Drawing Shapes

      Right-click anywhere on the map (or long-press on touch devices) to open the context menu. From there you can draw:

      • Circle - click centre, then edge
      • Rectangle - drag corners
      • Polygon - click vertices, double-click to finish
      • Line - click start and end points
      • Arrow - click tail, then tip
      • Flight Path - multi-point path with direction arrows
      • Text - add text on the map

      Text on the map

      For text shapes, the edit modal has Text on map (what is drawn), an optional Label for the sidebar list, and Text style: Label (dark pill, white text), Highlight (coloured text, no background), or Custom with your own text and background colours. You can set font size (px) for readability.

      Editing & copy / paste

      Editing Shapes

      Double-click a shape to open the edit modal. Click a shape to select and drag it. For arrows, select the arrow then drag its handles to rotate or resize. Use Edit Vertices from the context menu (or the vertices button in the sidebar) to adjust polygon/line points. For flight paths and lines, use the sidebar buttons to edit without clicking the narrow path. Measurement labels on circles and flight paths can be dragged to reposition them; you can also set label angle in the edit modal where shown.

      Copy & Paste

      Right-click a shape to copy it (Ctrl+C when selected), then right-click elsewhere to paste (Ctrl+V). Press Esc to deselect.

      Grid overlay & drawing style

      Grid Overlay

      Add a labelled grid over your map area for reference (e.g. search patterns, sector planning). Click the grid button on the map toolbar or choose Grid Overlay from the right-click context menu, then draw a rectangle to define the grid area. Set rows (1–50) and columns (1–26). Columns are labelled A–Z, rows 1–50. Right-click a grid cell to Edit Grid (change rows/columns or visibility) or Clear Grid.

      Drawing Style

      The Drawing Style section in the sidebar sets colour, fill opacity, stroke width, stroke style, and (for flight paths) arrow head size. Values apply to new shapes; when a shape is selected, they apply to that shape.

      Flight overview & distance

      Flight Overview

      For flight paths and lines, use Flight Overview to see altitude statistics. Click the altitude icon (▲) in the sidebar next to a flight path or line, or use the Flight Overview button when editing a shape. You can also right-click the path and choose Flight Overview, or tap the path and use Delete route in the popup. A modal shows start and end altitude, highest and lowest points, total variation, net change, total gain and loss, and average change per segment. A waypoint table lists each point with its coordinates, altitude (metres AMSL), and change from the previous point. Use Delete route in the modal footer to remove the path (with confirmation). For lines, start and end points are used. Elevation data requires a Mapbox token in js/config.js. On touch devices, long-press on a shape opens the same context menu as right-click, including Delete Shape.

      Flight Path Distance

      Flight paths can show total distance on the map. Use the Show distance on map checkbox when editing a flight path, or enable Show flight path distance on map in Settings to apply to all flight paths by default.

      Bulk Import

      Import many points at once via Upload CSV, Paste Data (tabular), or Paste List (one location per line). After parsing, map columns to: Latitude / Northing, Longitude / Easting, or a single Location column; plus optional Name / Label, Notes, Icon Type, Icon Colour (or Icon Color in CSV headers), and Icon Symbol. UK postcodes are supported with bulk lookup.

      Export

      Export points as CSV, or points and shapes as KML for use in other mapping tools. Screenshot Map captures the current map view as an image. Export as PowerPoint or Export as PDF generates a branded report with a map screenshot, points table, and shapes summary.

      Save & Load Project

      Save your entire project (points, shapes, settings) as a JSON file. Load it later to restore your work.

      Undo & redo

      Use Undo in the sidebar or map toolbar, or Ctrl+Z (Cmd+Z on Mac), to revert the last change. Use Redo, or Ctrl+Y, Ctrl+Shift+Z (Cmd+Shift+Z on Mac), to reapply a change you undid. Starting a new edit clears the redo history.

      Toolbar, search & geolocation

      Map Toolbar

      Along the top-left (several Leaflet controls): Locate (GPS position), Undo and Redo (stacked), Save Project, Load Project, Flight Path (dedicated draw control), then the main draw bar with Search (opens Search Location), Hand/Pan (exit draw modes and drag the map), Drop Point (opens the icon strip; pick a type, then click the map once), then Geoman tools: Circle, Grid Overlay, Rectangle, Polygon, Line, Arrow, and Text.

      Search Location

      Click the search button on the map toolbar to open the Search Location modal. Enter a postcode, lat/long, OS Grid ref, DMS, or What3Words address. The map will pan and zoom to that location.

      Geolocation

      Use the locate button to show your current position on the map.

      Map layers & UK airspace

      Map Layers

      Use the layer control (top-right) to switch between OpenStreetMap, Topographic, Satellite, and optionally Mapbox or Ordnance Survey (OS Maps requires an API key in Settings).

      UK Airspace

      The airspace key (bottom-right) shows all restriction types. Use Select all to show or hide all types, or tick individual types. Click the collapse button (▼) to minimise the panel.

      • Prohibited - No flying permitted
      • Restricted - Flying limited under certain conditions
      • Danger - Hazardous activities may occur
      • FRZ / Aerodrome - Flight Restriction Zones around protected aerodromes
      • NOTAM - Temporary restrictions from UK NOTAM Archive. Click the arrow (▼) for options: max radius (5-50 NM), drone-relevant only, and opacity. No API key required.
      • RA(T) - Restricted Area Temporary from BGA Airspace Service. Requires username and password in Settings (register at airspace.bgaladder.net).

      Data is sourced from UK AIP ENR 5.1 / NATS UAS. Click any zone for details including vertical limits and activation times. Use the refresh button (↻) to reload airspace data.

      To use real NATS data, see docs/AIRSPACE_DATA.md for download and conversion instructions.

      Sidebar, footer & small screens

      Sidebar & footer

      Collapse the sidebar (‹ button) for more map space. Use Fit All to zoom the map to include all points. Clear All removes every point (with confirmation); Clear Shapes removes all drawn shapes. The app footer includes Support (support@airplot.app), Privacy (policy), and Disclaimer (same content as the Disclaimer tab).

      Small screens

      On narrow viewports the left toolbar may collapse behind a Tools (☰) button; tap to expand. The Welcome control (top-left, same pattern as on the Weather, Airspace, Flight Report, and Checklist pages) returns to the welcome screen. Drawing Style is in the sidebar (between Actions and Points). A floating Help button (top-right on small screens) opens this help window. In this help window, swipe the tab row horizontally if not all tabs fit on one line; scroll the content below.

      Settings & keyboard shortcuts

      Settings

      Configure optional API keys (What3Words, OS Maps, BGA Airspace for RA(T)), and toggle display of point labels, shape measurements, shape labels, and flight path distance.

      Keyboard Shortcuts

      Escape - close modals, exit drawing/drop-point mode, deselect shapes. Ctrl+Z (Cmd+Z) - undo; Ctrl+Y or Ctrl+Shift+Z (Cmd+Shift+Z) - redo. Ctrl+C / Ctrl+V - copy and paste shapes.

      Flight Report

      Open Flight Report from the welcome screen or via flight-notes.html. Record date and time, location (search with postcode or address, or Use current GPS on HTTPS), mission fields (reference, deconflictions, remote pilots, UAS), up to four battery entries, optional Fetch weather report (Open-Meteo) into the Conditions field, NOTAMs and UK zones near your coordinates (Airspace section with small maps), and free-text notes. Theme (top bar) sets Dark or Light for the page; PDF theme next to Export PDF sets Dark or Light for the PDF only (default Light). Export with Export PDF or Send by email.

      Local draft: What you type is saved in this browser until you use Clear report (top of the page), Clear form (bottom, both with confirmation), or clear site data. Nothing is sent to AirPlot servers.

      Switch to Checklist: On Flight Report, the Checklist link in the top bar (next to Welcome) opens the M4T / TD checklist in the same tab so you can move between the report and the checklist without returning to the welcome screen.

      Checklist (M4T / TD)

      Open Checklist from the welcome screen or via checklist.html. The page lists pre-flight, take-off, landing, and post-flight sections with checkboxes, overall and per-section progress, Mark all complete per section, and optional short notes beside selected items (e.g. max altitude and max flight distance). Use Reset All to clear everything; confirmation uses the same modal style as elsewhere in AirPlot.

      Exports: Send by email builds a plain-text summary (mailto opens your mail app; long text may copy to the clipboard first). Export to PDF uses the browser print dialog (save as PDF). Both include an exported date and time. A duplicate progress and action bar appears at the bottom of the page so you do not need to scroll back to the top to reset or export.

      Local state: Checklist progress and notes are stored in this browser (not on our servers) until you reset or clear site data.

      Switch to Flight Report: On the checklist page, the Flight Report link in the top bar opens that page without going home.

      Welcome

      From any tool, Welcome (top-left) returns to the AirPlot welcome screen to choose another mode.

      Data Sources

      • UK Postcodes - postcodes.io (free, no API key required)
      • What3Words - What3Words API (requires API key)
      • Ordnance Survey Maps - OS Data Hub (requires API key)
      • OpenStreetMap - OpenStreetMap contributors (map tiles)
      • OpenTopoMap - OpenTopoMap (topographic tiles, SRTM elevation)
      • Mapbox - Mapbox (map tiles, Terrain-RGB elevation; requires token in config)
      • UK Airspace - UK AIP ENR 5.1 / NATS UAS (Prohibited, Restricted, Danger, FRZ)
      • UK NOTAM - UK NOTAM Archive (NATS AIS Contingency PIB, hourly updated)
      • RA(T) Airspace - BGA Airspace Service (requires username/password)
      • Open-Meteo - open-meteo.com (forecast data for the Weather page and optional fetch in Flight Report)
      • ADSB.lol - api.adsb.lol (live ADS-B JSON for the Airspace page)
      • Open Glider Network (OGN) - glidernet.org (optional FLARM-class live feed on the Airspace page)

      Coordinate Systems

      OS Grid Reference conversion uses Ordnance Survey National Grid (OSGB36) to WGS84 transformation (Airy 1830 ellipsoid).
