DJI Mission Planner Help

Build missions for DJI Pilot 2 (AirPlot v3.0). Switch modes with the toggles at the top of the toolbar.

Manual Recce

For overlay flight with a POI and exclusion fence (no automated route). Tap Add Target and click the map to place the point of interest. Adjust Radius (m) for the circular exclusion zone. Export Recce KMZ saves Recce_Mission.kmz for import as an overlay in DJI Pilot 2. Fly manually; the aircraft brakes at the fence.

Waypoint Mission

Tap Waypoint and click the map to add waypoints in order. Use Rectangle, Circle, or Polygon to draw exclusion zones (no-fly areas). Export KMZ produces a WPML mission file for automated flight. Undo reverts the last change; Clear removes everything.

Exports & reports

Export KMZ / Export Recce KMZ: mission files for the controller. PPTX and PDF: branded mission reports with a map capture. The SD card (?) button opens detailed import steps for DJI Pilot 2.

SD card & DJI Pilot 2

Use the SD card (?) button for step-by-step import: copy the KMZ to the card, insert into the controller, Flight Route → Import Route (KMZ/KML). FAT32 is recommended if the card is not read reliably.

Related

AirPlot map for general planning; Flight Weather for forecasts, METAR/TAF, and exports; Airspace for live ADS-B (optional OGN); Flight Report for structured records; M4T / TD Checklist for pre- through post-flight checks. From Report or Checklist, use the header links to switch between them without going home. Use Welcome (top-left) or the logo (bottom-right) to return to the AirPlot home screen.

Transfer mission to SD card

Copy your exported KMZ file onto an SD card and import it in DJI Pilot 2.

Manual Recce workflow

  1. Click Export Recce KMZ and save Recce_Mission.kmz to your computer.
  2. Copy the .kmz file onto an SD card (root or a folder such as DJI_Missions).
  3. Insert the SD card into your controller.
  4. In DJI Pilot 2, go to Flight Route → Import Route (KMZ/KML).
  5. Select the mission. Use it as an Overlay (do not press Start).
  6. Fly manually. The exclusion zone appears on the map. The drone brakes at the fence boundary.

Waypoint mission workflow

  1. Click Export KMZ and save the file to your computer.
  2. Copy the .kmz file onto an SD card (root or a folder such as DJI_Missions).
  3. Insert the SD card into your controller.
  4. In DJI Pilot 2, go to Flight Route → Import Route (KMZ/KML).
  5. Browse to the KMZ file and select it.
  6. The mission will appear in your mission library. Open it to review and fly.

Note: Use FAT32 formatting if the controller has trouble reading the SD card.
